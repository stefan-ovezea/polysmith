## Message Flow Example

```json
// 1. User creates setup
{"method": "cam_setup_create", "params": {...}, "id": 1}
{"result": {"setup_id": "cam_setup_abc123", ...}, "id": 1}

// 2. User selects pocket face (UI stores reference with attestation)
// 3. Create pocket operation
{"method": "cam_operation_create", "params": {
  "setup_id": "cam_setup_abc123",
  "operation_type": "pocket_2d",
  "geometry_references": {
    "machining_regions": [{
      "reference_type": "face",
      "primary_identification": {"persistent_id": "face_xyz789", ...},
      "geometric_attestation": {"area": 1234.5, "sample_points": [...], "bounds": {...}},
      "fallback_strategy": "require_revalidation"
    }]
  },
  "tool": {"tool_id": "endmill_6mm", "diameter_mm": 6.0, ...},
  "parameters": {"spindle_rpm": 8000, "feedrate_mm_per_min": 1200, "stepdown_mm": 1.0},
  "operation_specific_params": {"stepover_percent": 45, "clearing_strategy": "offset"}
}, "id": 2}

// 4. Generate preview (fast bounds)
{"method": "cam_toolpath_preview", "params": {"operation_id": "cam_op_456", "preview_level": "bounding_box"}, "id": 3}

// 5. Generate full toolpath (async)
{"method": "cam_toolpath_generate", "params": {"operation_id": "cam_op_456"}, "id": 4}
{"result": {"job_id": "job_789"}, "id": 4}

// 6. Poll status
{"method": "cam_job_status", "params": {"job_id": "job_789"}, "id": 5}

// 7. If TNP occurs on recompute, validation catches it
{"method": "cam_operation_validate", "params": {"operation_id": "cam_op_456", "current_body_id": "body_after_edit"}, "id": 6}
{"result": {
  "valid": false,
  "resolution_status": {
    "references_resolved": 0,
    "references_failed": 1,
    "failed_references": [{"original_id": "face_xyz789", "candidate_matches": [...], "fallback_used": false}]
  },
  "suggested_fixes": ["Re-select pocket face", "Roll back feature edit"]
}, "id": 6}
```

## Key Design Decisions

1. **Separation of concerns**: Setup owns machine/stock, operations own toolpaths
2. **Dependencies explicit**: Parent operation IDs, stock conditions
3. **TNP attestation on EVERY reference**: Sample points, area, bounds for re-identification
4. **Preview levels**: Bounding box (fast) → low-res (medium) → full (slow)
5. **Binary channel optional**: Fall back to JSON for small toolpaths
6. **Fallback strategies per reference**: Operation can decide how to handle failure
